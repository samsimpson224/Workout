Active Protocol

Entry Rule (Formula v2): Always enter the weight of ONE dumbbell and the working sets per exercise (for unilateral lifts, enter reps per side & sets per side — do not double sets for left+right).
What Actually Matters in Your Log (Formula v2):
  • Hard Sets First: The Clan Leaderboard ranks by Hard Sets by default so bodyweight differences or heavy leverage movements never skew competition.
  • Separated Raw Inputs vs. Calculated Score: Each logged workout permanently records your raw inputs (weight, sets, per-set reps, unilateral side mode, and session bodyweight snapshot) alongside Formula v2 effective load.
  • Single-Side Entry: On single-arm/leg exercises, enter 3 sets (not 6). If you enter a high set count by mistake, a yellow helper banner will offer a 1-tap fix!

Clan Leaderboard

A. Friends: join in 3 steps
  1. Install the app. Open the link your clan creator sent.
    iPhone: in Safari tap Share → Add to Home Screen → Add.
    Android: in Chrome tap the ⋮ menu → Add to Home screen (or Install app) → Add. Open it from the new icon.
  2. Paste the invite code. Tap the Clan tab → Join a clan. Copy the long code starting CLAN1. from your creator's message, then press and hold in the code box and tap Paste. Type a display name (and optionally choose a division).
  3. Tap Join & Bond with the Sanctuary. Log a workout and your name appears on the leaderboard. Every hard set you log contributes to bonding with the clan's weekly Sanctuary companion (capturing standard beasts at 85% target completion, ✦ sub-bosses at 92%, and ⚔ bosses at 100%!).
B. Clan creator: one-time setup (about 10 minutes, free)
  1. Go to console.firebase.google.com → Create project → Build → Authentication → Sign-in method → Enable Email/Password.
  2. Build → Realtime Database → Create Database → Rules tab: tap Copy rules below, paste into Firebase, and tap Publish.
C. Admin Surgical Edits, Audit & NordPass Support
  • 1-Click Audit & Live Repair: Unlock admin tools below to inspect and repair legacy data anomalies (duplicate template slots, accidental BW% on cable/row lifts, orphaned mod drops, duplicate member IDs, and unverified Sanctuary captures).
