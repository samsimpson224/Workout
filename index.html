Clan Leaderboard

A. Friends: join in 3 steps
  1. Install the app. Open the link your clan creator sent.
    iPhone: in Safari tap Share → Add to Home Screen → Add.
    Android: in Chrome tap the ⋮ menu → Add to Home screen (or Install app) → Add. Open it from the new icon.
  2. Paste the invite code. Tap the Clan tab → Join a clan. Copy the long code starting CLAN1. from your creator's message, then press and hold in the code box and tap Paste. Type a display name.
  3. Tap Join. Log a workout and your name appears on the board. That's it. No accounts or passwords for you.
B. Clan creator: one-time setup (about 10 minutes, free)

Easiest on a computer. On a phone, switch the page to desktop view first:
iPhone Safari: tap aA in the address bar → Request Desktop Website.
Android Chrome: tap ⋮ → tick Desktop site. Pinch to zoom as needed. On a phone, open Firebase's ☰ menu to see Build.

  1. Go to console.firebase.google.com and sign in with a Google account. Tap Create a project, name it (e.g. clan), Continue, switch Google Analytics off, Create project, Continue.
  2. Menu → Build → Authentication → Get started.
  3. Open the Sign-in method tab → Email/Password → turn on the first switch (not "Email link") → Save.
  4. Menu → Build → Realtime Database → Create Database. Pick the closest location, choose Start in locked mode, tap Enable.
  5. In Realtime Database open the Rules tab. Delete everything in the box. Tap Copy rules below, paste into the Firebase box, tap Publish. Set this up before? Copy the rules again: the new ones also support older clans.
  6. Go to Project overview (home) → tap the web icon </> → nickname → leave Hosting unticked → Register app. Select and copy the whole const firebaseConfig = {...} block. It must contain a databaseURL line; if not, step 4 isn't finished.
  7. Come back here: Start a clan → paste the block, enter your name and a master password → Create. Then tap Share invite code and send it to your friends.

Everything stays on Firebase's free plan. If Firebase asks for a card or a plan upgrade, stop and cancel. Button names occasionally change; pick the closest match.

C. How editing is protected
  • Everyone can only change their own entries. This is enforced by the database, not just the app.
  • Only you, with the master password, can hide a member or remove any entry (Unlock admin tools on the board). Your master password is never stored on your phone or shared.
  • Anyone holding the invite code can see the board, so only send it to your clan. Shared: display name plus each session's date, type, sets and estimated volume. Not shared: bodyweight or measurements. Note that estimated volume is calculated from bodyweight, so it reflects your size indirectly; untick "Share my estimated volume" on the board to keep that private.
D. Pokes
  • Tap Poke next to a member. They see a banner the next time they open the app, or within about a minute if it's already open. Pokes can't wake a closed app. For an instant phone notification, use Send a nudge by message.
  • Everyone in the clan can see who poked whom. You can poke the same person once every 30 minutes.
  • Pokes only work in clans created with the newest version.
E. Troubleshooting
  • Email/Password sign-in isn't switched on: redo step 3.
  • Firebase rules missing: redo step 5 and make sure you tapped Publish.
  • Invite code isn't valid: copy the whole code, with no spaces cut off.
  • Board empty: log a workout, then tap Sync my logs & refresh.
